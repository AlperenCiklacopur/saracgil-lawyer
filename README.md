# Saraçgil Hukuk Bürosu — Web Sitesi & Blog Yönetim Paneli

**Av. Melda Saraçgil** için [benjamincreative.me](https://benjamincreative.me/) sitesinin editoryal, koyu temalı ve modern görsel dilinde hazırlanmış resmi web sitesi ve blog yönetim sistemi.

## 🌟 Özellikler
- **Karanlık Lüks Editoryal Tasarım:** Benjamin Creative tarzı koyu zemin, antrasit kartlar, mikro etiketler ve yüksek tipografi kalitesi.
- **Rolling Text & Ticker:** Menü ve butonlarda akıcı "Rolling Text" animasyonu ve sonsuz kayan metin bandı (Marquee).
- **İcra & İflas Hukuku Odağı:** İlamsız/ilamlı icra, kambiyo senetleri (çek-senet), ihtiyati haciz, itirazın iptali ve konkordato süreçleri.
- **Blog & Arama Motoru:** Kategori filtreleme, anlık makale arama, okuma süreleri ve zengin başlangıç makaleleri.
- **Gizli Yönetici Girişi:** Footer'daki telif metninin sonundaki `•` noktasına tıklandığında (veya `Ctrl + Shift + A` kısayoluyla) açılan gizli kilit modalı.
- **Blog Yönetim Paneli (`/admin`):** Makale ekleme, düzenleme, silme, taslak/yayın yönetimi.
- **Vercel Uyumlu:** Yerel geliştirmede sıfır kurulumla çalışır, Vercel'de tek tıkla ücretsiz Upstash Redis / KV ile bulutta kalıcı depolama sunar.

## 🔑 Varsayılan Yönetici Bilgileri
- **Kullanıcı Adı:** `admin`
- **Şifre:** `saracgil2026!`

## 🚀 Çalıştırma
```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev

# Üretim derlemesi
npm run build
npm run start
```
Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresine gidin.
